## Frontend

Install dependencies with `npm install`, then start the React app with `npm start`.
Set `REACT_APP_GOOGLE_CLIENT_ID` and `REACT_APP_API_URL` in `.env.local`.

## Backend

The Express and MongoDB API is in [backend](./backend). Follow [backend/README.md](./backend/README.md) to configure MongoDB Atlas, Google OAuth, and the API environment before starting it.

Deployed site: https://bashabondhu.netlify.app/
